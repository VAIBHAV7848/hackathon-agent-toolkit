# Changelog

## 1.4.0 — Open-source ecosystem research and supply-chain awareness

- Added a curated, dated landscape of skill specifications, authoring guidance, skill registries, development harnesses, evaluators, security scanners, and professional UI skills.
- Analyzed God Harness as an architectural reference for bootstrap interviews, persistent context, impact analysis, and risk-proportionate process; did not vendor its code or skill text.
- Added selective-adoption rules: inspect license/provenance, maturity, scripts/hooks, network and filesystem access, prompt injection, and actual behavior before use.
- Added a reusable third-party skill audit report and six ecosystem-focused behavioral cases (E31–E36).
- Recommended independent structure/content validation plus with-skill vs without-skill behavioral tests; clean structural validation is not evidence of behavioral quality or security.
- Flagged the legacy `openai/skills` catalog as deprecated based on its current README; prefer the Agent Skills specification and current platform guidance.

## 1.3.0 — Modular universal skill and verifiable maintenance

- Refactored the 39 KB monolithic instruction file into a compact routing skill plus conditionally loaded reference modules.
- Preserved universal event/domain handling, planning-only boundaries, single-primary-builder defaults, and professional UI rules.
- Added read-only, dependency-free structural validation for frontmatter, required files, local references, and evaluation-case inventory.
- Expanded the manual behavioral suite from 20 to 30 cases, including prompt injection, stale state, tool unavailability, self-review independence claims, and progressive-loading behavior.
- Added an evaluation results CSV so structural validity and live behavioral validation cannot be conflated.
- Added a heuristic UI quality scorecard based on rendered evidence; critical defects block readiness regardless of score.

## 1.2.0 — Professional UI quality and evaluation improvements

- Added conditional professional UI design and rendered visual QA for projects with a real digital interface.
- Added anti-generic-AI visual constraints and evaluation cases for UI quality and evidence.

## 1.1.0 — Universal, adaptive skill

- Removed organizer-specific framing and added event/project modality classification.
- Added Rapid / Standard / Deep modes, project-state guidance, template routing, and manual behavioral evaluation scenarios.
