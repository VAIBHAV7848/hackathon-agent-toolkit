# Support

For usage questions and compatibility reports:

1. Read the root README and the README for the skill in question.
2. Run `python3 validate_toolkit.py` and include the output if it fails.
3. Report your toolkit version, operating system, coding CLI version, model, and
   exact skill invocation.
4. Provide a minimal reproduction without API keys, tokens, personal data, or
   private source code.

For confirmed bugs, use the bug-report issue template. For vulnerability
reports, follow `SECURITY.md` rather than publishing exploit details.

This project is community-maintained; no response time or compatibility level is
promised until the relevant environment has been tested and documented.
